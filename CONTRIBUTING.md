# Contributing

Use the issue forms for reports and corrections. Share only data you may lawfully publish: visible name, Play URL, exact package, version, reproducible behavior, device and Android version. Separate app UI, Android UI and embedded advertising.

Never upload APKs, malware samples, personal data, credentials, account identifiers or private screenshots.

A reported candidate is never promoted by name or popularity. An app-enforced rule requires exact package, signer, bounded versions, reproducible evidence, independent review and offline signing. Removal authorization is reviewed separately.
